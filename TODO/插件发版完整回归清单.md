# 插件发版完整回归清单

> 用途：每次准备发布浏览器插件新版本前，按这份清单手动点一遍，确认主要功能、关键流程和常见异常都没有问题。
>
> 适用范围：当前工作区代码，Chrome Manifest V3 侧边栏插件，主要入口为 `sidepanel.html`、`script.js`、`background.js`。
>
> 标记说明：
>
> - `【核心】`：必须重点验证，出问题会直接影响用户主流程
> - `【每次都测】`：建议每次版本都完整点一遍
> - `【新增重点】`：当前版本新增或近期改动较多的能力，发版前要额外确认

## 功能点总览

- [ ] 侧边栏基础 UI：公告栏、使用文档、反馈问题、赞助、获取当前网页地址、关注、Cookie、地址输入、设置、视频表格、进度圆环、Toast、弹窗。
- [ ] Cookie 能力：手动输入、自动保存、显示/隐藏、清空、从 B 站页面获取 Cookie、从 `document.cookie` 和 `chrome.cookies` 兜底读取、持久化到 `chrome.storage.local`。
- [ ] 视频导入能力：单个视频、个人主页、收藏夹、合集、视频选集、多 P、搜索页面、当前页面地址、BV/AV/b23 短链接、无协议 B 站链接。
- [ ] 视频列表能力：表格展示、标题/作者跳转、发布日期、字幕状态、字幕语言列、复制、删除、统计、空状态、横向滚动同步。
- [ ] 字幕获取能力：批量获取字幕语言轨道、WBI 签名、Cookie 请求头、视频详情补齐 `aid/cid/tags/description`、无字幕识别、充电专属拦截。
- [ ] 字幕内容能力：复制或导出时按需下载选中字幕内容，支持普通字幕、AI 字幕结构、字幕地址刷新与 403 后重试。
- [ ] 多语言字幕能力：单语言静态展示、多语言下拉、多选、全选、按语言复制、按语言导出、文件名追加语言后缀。
- [ ] 本地转写能力：无外挂字幕队列、转写确认弹窗、跳过提醒设置、获取 DASH 音频流、多音频 URL 兜底、页面上下文下载、直接下载、前端解码兜底、本地 Whisper 转写、语言识别、分块、去重、SRT 生成。
- [ ] 导出能力：TXT / MD / DOC / SRT，ZIP 压缩和单个文件下载，文件命名格式，纯文本头部信息多选，Chrome 下载行为兼容。
- [ ] 增长入口：顶部公告栏、关注按钮、赞助按钮、使用文档、反馈问题、解析次数里程碑关注弹窗。
- [ ] 发版资源：`manifest.json` 权限、图标、`libs/`、`models/`、`jszip.min.js`、`web_accessible_resources`、CSP。

## 本次清单更新要点

- [ ] 搜索页面导入要按当前实现测试：输入框校验搜索 URL，但实际抓取依赖当前激活的 B 站搜索页面 DOM。
- [ ] 字幕获取现在优先获取字幕语言轨道，字幕正文在复制或导出时按需下载，需要把“获取字幕成功”理解为“已拿到可用字幕轨道”。
- [ ] 字幕语言列新增多选和“转写”快捷入队能力：有外挂字幕但没有想要语言时，可以手动加入无外挂字幕队列。
- [ ] 纯文本头部信息已从单一开关升级为多选字段：全部、标题、链接、作者、发布日期、标签、视频简介。
- [ ] 导出需要同时覆盖 ZIP 和单个文件模式，单个文件模式依赖 `chrome.downloads.download`，也要测 Chrome 下载保存设置。
- [ ] 转写链路新增本地 Whisper 语言识别、非中文文本格式处理、前端解码兜底、打开 B 站页面辅助下载音频等路径。
- [ ] 充电专属视频现在应统一显示 `充电专属不可获取`，不能进入普通获取字幕或转写流程。
- [ ] TXT / MD / DOC 的正文转换需要分别测中文断句、非中文不套中文断句、繁简转换、乱码过滤和重复行去重。

## 1. 基础打开【每次都测】

- [ ] 打开插件侧边栏，页面正常显示，没有空白、错位、按钮消失、明显重叠。
- [ ] 顶部按钮都能看到：`使用文档`、`反馈问题`、`赞助我`、`获取当前网页地址`、`关注我`。
- [ ] 主操作按钮都能看到：`获取视频`、`获取Cookie`、`获取字幕`、`转写无字幕`、`导出字幕`、`清空表格`。
- [ ] 表格、顶部统计、设置按钮、字幕状态帮助图标、无字幕提示条区域都能正常显示。
- [ ] 进度圆环默认不遮挡内容，处理时能显示，处理结束后能自动隐藏。
- [ ] Toast 成功/错误提示位置正常，关闭按钮可点，3 秒左右可自动消失。
- [ ] 侧边栏宽度较窄时，按钮文字、表格列、下拉框不明显溢出或遮挡。

## 2. Cookie 相关【每次都测】

- [ ] Cookie 输入框默认是隐藏状态，不直接明文显示。
- [ ] Cookie 输入框为空时，不显示多余的清空按钮和显示/隐藏按钮。
- [ ] 手动输入 Cookie 后，可以正常显示/隐藏内容。
- [ ] 手动输入、失焦、按回车后，Cookie 会自动保存。
- [ ] 点击 Cookie 清空按钮后，输入框内容被清空，并同步清空本地保存的 Cookie。
- [ ] 关闭并重新打开侧边栏后，已保存 Cookie 的读取状态符合预期。
- [ ] 在已登录 B 站的情况下点击 `获取Cookie`，能成功把 Cookie 回填到输入框。
- [ ] 获取到的 Cookie 至少应包含或提示检查 `SESSDATA`、`bili_jct`、`DedeUserID` 等关键项。
- [ ] 未登录 B 站时点击 `获取Cookie`，会给出明确提示，不会卡死。
- [ ] 当前页面不在 B 站时点击 `获取Cookie`，会提示前往 B 站，并新开 B 站页面。

## 3. 地址类型切换【每次都测】

- [ ] 地址类型下拉框能正常展开、收起。
- [ ] 下拉框中能看到全部地址类型：`单个视频`、`个人主页`、`收藏夹`、`合集`、`视频选集`、`搜索页面`。
- [ ] 切换不同地址类型后，输入框提示文案会跟着变化。
- [ ] 选择 `单个视频` 时显示单视频添加按钮；选择其他类型时显示批量获取按钮。
- [ ] 切换地址类型后，不会出现按钮错乱、图标丢失或点击无反应。
- [ ] 输入框右侧清空按钮可用，清空后不会保留旧的视频信息状态。

## 4. 地址格式兼容【核心】

- [ ] 单视频支持标准 BV 链接。
- [ ] 单视频支持 `av` 老链接。
- [ ] 单视频支持 b23 短链接。
- [ ] 输入不带 `https://` 的 B 站链接时，能自动按 B 站地址解析。
- [ ] 收藏夹支持 `space.bilibili.com/{mid}/favlist?fid=...`。
- [ ] 收藏夹支持 `/medialist/detail/ml...` 或 `/medialist/play/ml...` 格式。
- [ ] 收藏夹支持 `/fav/ml...` 或 `/list/ml...` 等短路径格式。
- [ ] 个人主页只接受 `space.bilibili.com/{mid}` 或 `/{mid}/video` 这类主页地址。
- [ ] 搜索页面只接受 `search.bilibili.com/all` 或 `search.bilibili.com/video` 且带 `keyword` 的链接。
- [ ] 输入明显错误的地址时，会按当前地址类型给出明确提示。

## 5. 获取当前网页地址【每次都测】

- [ ] 在 B 站视频页点击 `获取当前网页地址`，输入框能自动填入当前页面地址。
- [ ] 在 B 站个人主页 / 收藏夹 / 合集 / 搜索页点击 `获取当前网页地址`，填入内容符合当前页面。
- [ ] 当前页不是 B 站页面时，填入行为和提示符合预期，不会影响已有表格数据。

## 6. 单个视频导入【每次都测】

- [ ] 视频详情能补齐 `bvid`、`aid`、`cid`、时长、标签、视频简介等后续流程需要的数据。
- [ ] 重复添加同一个视频时，不会无限重复添加。
- [ ] 同一个多 P 视频的不同 `cid` 在视频选集模式下可以作为不同分 P 项存在。
- [ ] 视频标题或作者含特殊字符时，不影响表格展示和后续文件命名。

- [ ] 收藏夹视频较多时，分页获取过程能正常完成。

- [ ] 私密或需要登录的收藏夹，在 Cookie 有效时能正常获取；Cookie 缺失时提示清楚。

- [ ] 合集视频作者能优先使用合集 UP 主信息，不显示成空白。

## 10. 视频选集导入【每次都测】

- [ ] 选择 `视频选集`，输入带分 P 的视频链接，能成功识别并导入选集内容。
- [ ] 导入后能看到多条对应的视频项。
- [ ] 分 P 标题格式包含主标题、P 序号和分 P 标题。
- [ ] 点击分 P 视频标题时，打开链接带正确的 `?p=` 参数。
- [ ] 分 P 去重按 `bvid + cid` 判断，不会错误合并不同分 P。
- [ ] 普通单 P 视频在视频选集模式下有合理提示。

## 11. 搜索页面导入【核心】【新增重点】

- [ ] 选择 `搜索页面`，输入一个有效的 B 站搜索页链接。
- [ ] 点击获取前，浏览器当前激活标签页必须切到对应 B 站搜索页面。
- [ ] 当前激活标签页是对应搜索页面时，能从页面结果中提取视频并加入表格。
- [ ] 当前激活标签页不是搜索页面时，会提示 `请先打开并切换到对应的B站搜索页面`。
- [ ] 搜索结果页面还没加载完成时，会提示当前页面没有可添加的视频，不会卡死。
- [ ] 搜索页导入后，表格里的标题、作者、发布日期显示正常。
- [ ] 搜索结果中的广告、无效 BV、重复 BV 不应进入表格或重复添加。
- [ ] 重复导入同一个搜索页，不会无限重复添加同样的视频。
- [ ] 搜索页链接错误、缺少 `keyword` 或格式不对时，会给出明确提示。

## 12. 表格基础表现【每次都测】

- [ ] 表格为空时，会显示空状态提示。
- [ ] 添加视频后，顶部 `(总共 / 获取成功)` 统计会正常变化。
- [ ] 点击视频标题，能打开对应视频页面。
- [ ] 分 P 视频标题链接能打开对应 P。
- [ ] 点击作者名称，能打开对应作者主页。
- [ ] 删除单条视频后，表格和统计数字会同步更新。
- [ ] 表格横向滚动时，表头和表体能同步滚动。
- [ ] 字幕状态帮助图标 hover 时，能显示充电专属说明。
- [ ] 表格内长标题、长作者名、长状态文案不会造成严重错位。

## 13. 获取字幕【核心】

- [ ] 表格中有视频时，点击 `获取字幕`，按钮会进入处理中状态。
- [ ] 进度圆环会显示获取进度和状态文案。
- [ ] 已经有字幕内容或字幕轨道的视频，再次点击 `获取字幕` 会跳过，不重复请求。
- [ ] 有外挂字幕的视频，最终状态显示为成功状态，表格文案为 `外挂字幕`。
- [ ] 成功后默认选中第一个字幕语言轨道。
- [ ] 获取字幕阶段只拿语言轨道时，也应计入顶部成功统计。
- [ ] 无外挂字幕的视频，最终状态会明确显示 `无外挂字幕`。
- [ ] 获取失败或信息异常时，会显示清晰的失败/异常提示。
- [ ] 获取完成后，顶部统计数字会正确更新。
- [ ] 表格中混合存在“有字幕视频 / 无字幕视频 / 异常视频 / 已成功视频”时，整批处理能正常结束。

## 14. 字幕接口和内容下载【核心】【新增重点】

- [ ] 字幕语言列表请求能正常走 WBI 签名接口。
- [ ] WBI 接口失败或返回异常时，有明确错误提示，不静默失败。
- [ ] 字幕正文在点击复制或导出时按需下载，不要求获取字幕阶段立即下载正文。
- [ ] 字幕内容下载时，普通 `body[]` 结构能转为统一 `subtitleText`。
- [ ] AI 字幕结构 `type === 'AIsubtitle'` 且有 `body[]` 时能正确解析。
- [ ] 字幕 URL 为空但可通过 AI 字幕检索拿到地址时，能正常兜底。
- [ ] 字幕内容下载遇到 403 时，会尝试刷新同语言字幕地址并重试。
- [ ] 带来源头请求失败时，简化请求兜底能正常尝试。

## 15. 充电专属和受限视频【核心】【新增重点】

- [ ] 如有充电专属视频，获取视频信息后能识别 `is_upower_exclusive`。
- [ ] 充电专属视频点击 `获取字幕` 后，状态显示 `充电专属不可获取`。
- [ ] 充电专属视频不会被误标为 `无外挂字幕`。
- [ ] 充电专属视频不会进入转写队列。
- [ ] 批量结果提示中能体现跳过数量。
- [ ] 状态帮助图标说明与实际行为一致。

## 16. 无外挂字幕提示条【每次都测】

- [ ] 当表格里存在 `无外挂字幕` 的视频时，表格上方会出现提示条。
- [ ] 提示条文案包含无外挂字幕数量。
- [ ] 提示条能引导用户点击 `转写无字幕`。
- [ ] 当没有无外挂字幕视频时，这条提示不会错误显示。
- [ ] 从无字幕状态转写成功后，提示条数量会同步减少或消失。

## 17. 转写无字幕【核心】【新增重点】

- [ ] 点击 `转写无字幕` 时，会先弹出提醒弹窗。
- [ ] 提醒弹窗包含准确率、首次加载模型、耗时、本地配置、不要关闭侧边栏等提示。
- [ ] 提醒弹窗里的 `取消` 按钮可以正常关闭，不会开始转写。
- [ ] 点击遮罩空白处关闭弹窗时，不会开始转写。
- [ ] 点击 `确认转写` 后，才会正式开始处理。
- [ ] `下次不再提示` 勾选后，再次转写时符合预期，并能持久化。
- [ ] 转写过程中按钮进入加载态，进度圆环持续更新。
- [ ] 转写过程中显示 `请勿关闭插件侧边栏` 提醒。
- [ ] 表格中同时存在多个无字幕视频时，可以批量依次转写。
- [ ] 超过 60 分钟的视频，不会继续转写，并会给出明确提示。
