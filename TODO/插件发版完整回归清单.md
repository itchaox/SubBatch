# 插件发版完整检查清单

> 用途：每次准备发布浏览器插件新版本前，按这份清单手动点一遍，确认主要功能、关键流程和常见异常都没有问题。
>
> 标记说明：
>
> - `【核心】`：必须重点验证，出问题会直接影响用户主流程
> - `【每次都测】`：建议每次版本都完整点一遍

## 1. 基础打开【每次都测】

- [ ] 打开插件侧边栏，页面正常显示，没有空白、错位、按钮消失、明显重叠。
- [ ] 顶部主要按钮都能看到：`获取当前网页地址`、`获取Cookie`、`获取字幕`、`转写无字幕`、`导出字幕`、`清空表格`。
- [ ] 表格、顶部统计、设置按钮、关注按钮都能正常显示。
- [ ] 点击 `关注我`，能正常打开作者主页。

## 2. Cookie 相关【每次都测】

- [ ] Cookie 输入框默认是隐藏状态，不直接明文显示。
- [ ] Cookie 输入框为空时，不显示多余的清空按钮和显示/隐藏按钮。
- [ ] 手动输入 Cookie 后，可以正常显示/隐藏内容。
- [ ] 点击 Cookie 清空按钮后，输入框内容被清空。
- [ ] 在已登录 B 站的情况下点击 `获取Cookie`，能成功把 Cookie 回填到输入框。
- [ ] 未登录 B 站时点击 `获取Cookie`，会给出明确提示，不会卡死。

## 3. 地址类型切换【每次都测】

- [ ] 地址类型下拉框能正常展开、收起。
- [ ] 下拉框中能看到全部地址类型：`单个视频`、`个人主页`、`收藏夹`、`合集`、`视频选集`、`搜索页面`。
- [ ] 切换不同地址类型后，输入框提示文案会跟着变化。
- [ ] 切换地址类型后，不会出现按钮错乱或点击无反应。

## 4. 获取当前网页地址【每次都测】

- [ ] 在 B 站视频页点击 `获取当前网页地址`，输入框能自动填入当前页面地址。
- [ ] 在 B 站个人主页 / 收藏夹 / 合集 / 搜索页点击 `获取当前网页地址`，填入内容符合当前页面类型。

## 5. 单个视频导入【每次都测】

- [ ] 选择 `单个视频`，输入一个正常的视频链接，能成功加入表格。
- [ ] 加入表格后，标题、作者、发布日期、字幕状态显示正常。
- [ ] 重复添加同一个视频时，不会无限重复添加。

## 6. 个人主页导入【每次都测】

- [ ] 选择 `个人主页`，输入一个 UP 主页链接，能成功获取该 UP 的视频列表。
- [ ] 表格中能正确显示多条视频数据。
- [ ] 获取失败时，有明确提示，不会一直停在加载状态。

## 7. 收藏夹导入【每次都测】

- [ ] 选择 `收藏夹`，输入收藏夹链接，能成功导入收藏夹中的视频。
- [ ] 收藏夹视频较多时，分页获取过程能正常完成。
- [ ] 导入结束后，表格数量与预期大致一致。

## 8. 合集导入【每次都测】

- [ ] 选择 `合集`，输入合集链接，能成功导入合集中的视频。
- [ ] 合集内多条视频都能正常进入表格。

## 9. 视频选集导入【每次都测】

- [ ] 选择 `视频选集`，输入带分 P 的视频链接，能成功识别并导入选集内容。
- [ ] 导入后能看到多条对应的视频项。

## 10. 搜索页面导入【核心】

- [ ] 选择 `搜索页面`，输入一个有效的 B 站搜索页链接，能成功把当前页的视频结果加入表格。
- [ ] 搜索页导入后，表格里的标题、作者、发布日期显示正常。
- [ ] 重复导入同一个搜索页，不会无限重复添加同样的视频。
- [ ] 搜索页链接错误或格式不对时，会给出明确提示。

## 11. 表格基础表现【每次都测】

- [ ] 表格为空时，会显示空状态提示。
- [ ] 添加视频后，顶部 `(总共 / 获取成功)` 统计会正常变化。
- [ ] 点击视频标题，能打开对应视频页面。
- [ ] 点击作者名称，能打开对应作者主页。
- [ ] 删除单条视频后，表格和统计数字会同步更新。

## 12. 获取字幕【核心】

- [ ] 表格中有视频时，点击 `获取字幕`，按钮会进入处理中状态。
- [ ] 有外挂字幕的视频，最终状态会变成成功状态。
- [ ] 无外挂字幕的视频，最终状态会明确显示 `无外挂字幕`。
- [ ] 获取失败或信息异常时，会显示清晰的失败/异常提示。
- [ ] 获取完成后，顶部统计数字会正确更新。
- [ ] 表格中混合存在“有字幕视频 / 无字幕视频 / 异常视频”时，整批处理能正常结束。

## 13. 无外挂字幕提示条【每次都测】

- [ ] 当表格里存在 `无外挂字幕` 的视频时，表格上方会出现提示条。
- [ ] 提示条文案清楚，能引导用户点击 `转写无字幕`。
- [ ] 当没有无外挂字幕视频时，这条提示不会错误显示。

## 14. 转写无字幕【核心】

- [ ] 点击 `转写无字幕` 时，会先弹出提醒弹窗。
- [ ] 提醒弹窗里的 `取消` 按钮可以正常关闭，不会开始转写。
- [ ] 点击 `确认转写` 后，才会正式开始处理。
- [ ] `下次不再提示` 勾选后，再次转写时符合预期。
- [ ] 转写过程中会显示进度，不会完全无反馈。
- [ ] 转写成功后，对应视频状态会变成成功状态。
- [ ] 转写失败时，会有明确失败提示，不会静默失败。
- [ ] 表格中同时存在多个无字幕视频时，可以批量依次转写。
- [ ] 超过 60 分钟的视频，不会继续转写，并会给出明确提示。

## 15. 字幕语言列【核心】

- [ ] 对没有字幕内容的视频，字幕语言列显示合理，不会出现错乱内容。
- [ ] 对只有一种外挂字幕语言的视频，字幕语言列能正常显示该语言。
- [ ] 对有多个外挂字幕语言的视频，字幕语言列能正常展开语言下拉。
- [ ] 下拉中能看到 `全部` 选项和各个具体语言选项。
- [ ] 点击 `全部` 后，所有语言都会被选中。
- [ ] 取消其中一个语言后，`全部` 状态会自动取消。
- [ ] 只选中一个语言时，显示内容符合预期。
- [ ] 选中多个语言时，显示内容符合预期。
- [ ] 转写字幕的视频，字幕语言列显示为静态语言标签，不会错误显示成下拉框。

## 16. 复制字幕【核心】

- [ ] 对已经成功获取字幕的视频，操作列会出现复制按钮。
- [ ] 单语言状态下，点击复制按钮后，字幕内容能正常复制出来。
- [ ] 多语言同时选中时，复制按钮应符合预期，不会错误复制不明确内容。
- [ ] 对没有字幕内容的视频，不会错误显示可复制状态。

## 17. 导出字幕【核心】

- [ ] 有可用字幕时，点击 `导出字幕`，能正常进入导出流程。
- [ ] 当导出格式为 `每次询问` 时，会先弹出格式选择。
- [ ] 选择 `TXT` 后，能成功导出 TXT 文件。
- [ ] 选择 `SRT` 后，能成功导出 SRT 文件。
- [ ] 多个视频一起导出时，会正常打包，不会只导出一部分。
- [ ] 没有任何可导出字幕时，点击导出会有明确提示。

## 18. 多语言字幕导出【核心】

- [ ] 对多语言外挂字幕视频，只选中一个语言时，只会导出对应语言文件。
- [ ] 选中多个语言时，会导出多个对应文件。
- [ ] 选中 `全部` 时，会导出该视频全部已选语言文件。
- [ ] 多个语言文件的命名能区分开，不会互相覆盖。

## 19. TXT 头部信息开关【每次都测】

- [ ] `导出 TXT 时添加视频信息` 开关可以正常开关。
- [ ] 鼠标移到右侧说明图标上时，会显示提示说明。
- [ ] 开启开关后，导出的 TXT 顶部会带视频标题和链接。
- [ ] 关闭开关后，导出的 TXT 不再带标题和链接。
- [ ] 该开关不应影响 SRT 导出。

## 20. 导出格式设置【每次都测】

- [ ] 在设置里切换 `导出格式` 后，重新打开设置，选项仍然保持。
- [ ] `TXT 格式（纯文本）`、`SRT 格式（带时间戳）`、`每次询问` 都能正常选择。

## 21. 文件命名格式设置【每次都测】

- [ ] 文件命名格式下拉框能正常展开。
- [ ] 5 个命名格式选项都能完整显示。
- [ ] 每个命名格式示例都能正常看到。
- [ ] 切换命名格式后，导出的文件名与设置一致。

## 22. 设置弹窗【每次都测】

- [ ] 点击设置按钮，设置弹窗能正常打开。
- [ ] 点击右上角关闭按钮，设置弹窗能正常关闭。
- [ ] 按 `Esc` 键时，设置弹窗也能关闭。
- [ ] 点击弹窗外部区域时，设置弹窗能关闭。

## 23. 清空表格【核心】

- [ ] 点击 `清空表格` 后，会先弹出确认提示。
- [ ] 点击 `取消` 后，表格内容保持不变。
- [ ] 点击 `确认清空` 后，表格内容会被清空。
- [ ] 清空后会恢复为空状态提示。
- [ ] 清空后顶部统计数字会归零并隐藏。

## 24. 关键异常场景【核心】

- [ ] 空表状态下点击 `获取字幕`，会有明确提示。
- [ ] 空表状态下点击 `转写无字幕`，会有明确提示。
- [ ] 空表状态下点击 `导出字幕`，会有明确提示。
- [ ] 输入明显错误的 B 站地址时，会有明确提示。
- [ ] 网络较慢或接口异常时，页面不会卡死到无法继续操作。
- [ ] 如有充电专属视频，状态提示符合预期，不会误当作普通视频处理。

## 25. 发版前最终确认【核心】

- [ ] 至少完成一次：`单个视频 → 获取字幕 → 导出 TXT`
- [ ] 至少完成一次：`无外挂字幕视频 → 转写无字幕 → 导出 TXT`
- [ ] 至少完成一次：`批量导入多个视频 → 批量获取字幕/转写 → 批量导出`
- [ ] 至少完成一次：`多语言外挂字幕视频 → 切换字幕语言 → 导出`
- [ ] 至少完成一次：`搜索页面导入 → 获取字幕 → 导出`
- [ ] 检查页面文案，没有明显错别字、状态文案混乱、按钮名称不统一的问题。
- [ ] 确认本次版本新增功能都已经手动点过一遍。
