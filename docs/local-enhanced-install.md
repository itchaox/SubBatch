# SubBatch 本地增强版安装说明

本地增强版保留高质量音频转字幕能力，内置 Whisper 模型，适合需要把无字幕视频转成 TXT/SRT 并用于 AI 知识库的用户。

## Chrome 安装

1. 下载并解压 `subbatch-local-enhanced.zip`。
2. 打开 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 `subbatch-local-enhanced` 文件夹。
6. 打开 B 站页面后点击扩展图标，在侧边栏中使用。

## Edge 安装

1. 下载并解压 `subbatch-local-enhanced.zip`。
2. 打开 `edge://extensions`。
3. 开启左侧“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择解压后的 `subbatch-local-enhanced` 文件夹。
6. 打开 B 站页面后点击扩展图标，在侧边栏中使用。

## 使用提醒

- 首次转写会加载本地模型，等待时间较长。
- 转写速度和效果取决于电脑配置。
- 转写过程中请保持侧边栏打开。
- 商店版不包含本地模型，也不提供音频转字幕功能。
