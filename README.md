# 字幕批量处理

字幕批量处理是一个浏览器扩展，可以帮助用户获取 B 站视频标题和字幕数据，并提供导出字幕文件功能。

## 主要功能

1. 获取 B 站视频信息（标题、作者、播放量、点赞数）
2. 获取 B 站视频字幕并支持导出为 TXT 文件
3. 支持直接跳转到视频页面

## 使用方法

1. 在输入框中粘贴 B 站视频 URL，或使用"获取当前页面地址"按钮获取当前浏览的视频 URL
2. 点击"获取视频标题"按钮获取视频信息
3. 点击"获取字幕"按钮获取视频字幕（仅当视频有字幕时可获取）
4. 点击"导出字幕"按钮将字幕导出为 TXT 文件

## 技术实现

- 使用 Chrome Extension API
- 通过 B 站官方 API 获取视频信息和字幕数据
- 支持导出字幕为 TXT 格式文件
