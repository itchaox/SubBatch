# Lark Base Helper - 飞书多维表格助手

一款帮助你更高效地使用飞书多维表格的浏览器插件

## ✨ 功能特点

- 🔍 **快速配置插件**：轻松选择并配置多维表格插件
- 🎨 **界面定制**：支持隐藏侧边栏、隐藏头部等
- 👀 **视图管理**：支持隐藏新增视图按钮
- 🔎 **插件搜索**：支持快速搜索飞书多维表格已有的侧边栏插件
- 📏 **宽度调整**：支持自定义侧边栏展开宽度

## 📖 使用说明

1. **获取表格地址**

   - 点击"获取当前多维表格地址"按钮，自动获取当前页面的地址
   - 或手动输入多维表格的地址

2. **配置选项**

   - 隐藏侧边栏：隐藏多维表格左侧的导航栏
   - 隐藏头部：隐藏多维表格顶部的导航栏
   - 隐藏新增视图：隐藏新增视图按钮
   - 打开插件市场：自动打开插件市场面板

3. **选择插件**

   - 在插件列表中选择需要的插件
   - 使用搜索框快速查找插件
   - 点击插件行可以选中/取消选中

4. **生成地址**
   - 点击"生成新表格地址"按钮
   - 使用"一键预览"直接打开配置后的页面
   - 或使用"复制地址"获取配置后的链接

## 🎯 使用场景

- 需要快速配置多维表格插件的用户
- 需要定制多维表格界面的用户
- 需要管理多个插件的用户
- 需要优化工作效率的用户

## 🛡️ 隐私声明

本扩展程序：

- 不会收集任何用户数据
- 不会记录用户的浏览历史
- 只在用户访问飞书多维表格时工作
- 所有配置都保存在本地
